# Smart Text Selection Assistant

A lightweight web application built with HTML, CSS, and JavaScript that enhances text interaction using modern browser APIs.

## Features

* Smart text selection menu
* Copy selected text to clipboard
* Share selected text on X (Twitter)
* Highlight important text
* Dark / Light theme toggle
* Local storage support for saved highlights
* Dynamic DOM manipulation

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Selection API
* Local Storage API
* Clipboard API

## How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/smart-text-selection-assistant.git
```

2. Open the project folder

```bash
cd smart-text-selection-assistant
```

3. Open `index.html` in your browser

or

Run with VS Code Live Server.
